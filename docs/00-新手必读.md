# 新手必读（零基础也能搭起来）

这篇是给**完全没接触过**的人写的。跟着做，大约 **30–40 分钟**（其中 20 分钟是下载和安装）。
每一步都告诉你：**做什么 → 应该看到什么 → 不是这样就怎么办**。

> 老手请直接 `pool.bat setup` → 看 [QUICKSTART.md](QUICKSTART.md)。

---

## 一、先搞清楚这东西是什么（30 秒）

一句话：**把很多个 ChatGPT 账号装进很多个"指纹浏览器窗口"里，然后用一句命令让它们帮你画图。**

```
你运行  pool.bat gen "一只柴犬"
        ↓
后台（FPBrowser2API）从池子里挑一个空闲窗口
        ↓
窗口里的插件（浏览器扩展）替你操作 ChatGPT 画图
        ↓
原图下载到你的 output 目录
```

三个名词先记住：

| 名词 | 通俗解释 |
|---|---|
| **卡密** | 别人卖给你的账号信息，一串长这样：`邮箱----密码----2FA----access_token` |
| **指纹浏览器** | 可以创建很多个"互相隔离的浏览器窗口"的软件，本方案用 **VirtualBrowser** |
| **号池** | 这些窗口 + 账号的集合。池子越大，能同时画的图越多 |
| **预热** | 新窗口第一次启动比较慢，要先"跑一遍"让插件连上、让目标网页状态就绪 |

## 二、你需要准备什么

| 必需 | 说明 | 去哪弄 |
|---|---|---|
| ① Windows 电脑 | Win10/11 都行，建议 16G 内存 | — |
| ② VirtualBrowser 客户端 | 指纹浏览器本体（约 1–2 GB） | 从服务商/作者处获取安装包，一路默认安装即可 |
| ③ Python 3.11 或 3.12 | 装的时候**务必勾选 `Add python.exe to PATH`** | python.org/downloads |
| ④ 卡密文件 | 每行一个账号，几十个也行，1 个也能跑 | 你的卡密供应商 |
| ⑤ 本 Skill 目录 | 就是你正在看的这个文件夹 | 解压/克隆到本地即可 |

> 代理（IP）不是必需的：没有代理也能跑，只是**同一个出口 IP 上账号越多，联动风控风险越高**。
> 有代理就写进 `proxies.txt`，导入时用 `--proxy-file proxies.txt`。

## 四、分步详解（每步都有"应该看到什么"）

### 第 1 步：装 VirtualBrowser 客户端
- **做什么**：运行安装包，全部默认下一步。装完先**不要**手动打开窗口。
- **应该看到什么**：安装目录里有 `VirtualBrowser.exe` 和一个 `api_server` 文件夹。
- **不是这样**：装的目录不对也能跑，只要 `pool.bat doctor` 能找到；找不到就设环境变量
  `set VB_ROOT=D:\你的\VirtualBrowser`。

### 第 2 步：装 Python
- **做什么**：装 3.11 或 3.12，**勾选 Add to PATH**。
- **应该看到什么**：打开 cmd 输入 `python --version` 显示 `Python 3.11.x`。
- **不是这样**：提示"不是内部或外部命令"→ 重装 Python 并勾选 Add to PATH。

### 第 3 步：放好本 Skill
- **做什么**：把本目录放到一个**路径不含空格**的位置，例如 `D:\生图号池搭建skill`。
- **为什么**：路径里的空格和特殊字符容易让某些命令行工具出错。
- **应该看到什么**：目录里有 `pool.bat`、`scripts\`、`docs\`。

### 第 4 步：一键搭建（`pool.bat` → `9`，即 `pool.bat setup`）
它会自动做 9 件事，**可以反复运行**，已经做过的会自动跳过：
```
1 环境体检   2 定位/克隆代码   3 建 venv 装依赖   4 打补丁
5 写配置     6 装浏览器扩展    7 后台起服务       8 建号池骨架   9 自检
```
- **应该看到什么**：结尾出现 `✅` 列表，最后一行是"下一步（复制即用）"。
- **不是这样**：看到 `❌` 就照它下面的 `→` 做，然后**再跑一次 `pool.bat setup`**。
  - 提示"未找到 VirtualBrowser" → 客户端没装或没装完
  - 提示"pip 安装失败" → 会自动换国内镜像重试；仍失败就手动跑它给出的命令
  - 提示"端口被占用" → 之前起过服务，正常；用 `pool.bat status` 确认

### 第 5 步：填卡密（`accounts.txt`）
新建文本文件 `accounts.txt`，每行一个账号（**用记事本另存为 UTF-8 或 ANSI 都行**）：
```
user1@example.com----密码A----JBSWY3DPEHPK3PXP----eyJhbGciOi...
user2@example.com----密码B----KRSXG5CTMVRXEZLU----eyJhbGciOi...
```
- **关键**：分隔符是 **四个短横线 `----`**；第 4 段（`access_token`）最长，一定要整段粘全，别换行。
- **没有第 4 段？** 只要有 token 就能跑（本方案走 token 直灌，不需要邮箱验证码和 2FA）；
  但请把文件按原样保留，将来 token 过期时用得上。
- **应该看到什么**：粘贴后保存，文件里每行都是一整行（没有被记事本折行）。

### 第 6 步：导入卡密（`pool.bat` → `4`，即 `pool.bat import accounts.txt --yes`）
- **应该看到什么**：打印每个账号的 `token 校验 → OK`，最后写库成功；并且**自动备份了数据库**。
- **先小后大**：第一次建议 `pool.bat import accounts.txt --yes --only 1` 只导 1 个，跑通整条链路
  再加量（`--only 1` 表示只导前 1 个）。
- **不是这样**：
  - `token 校验失败` → token 粘错了或已过期，换一条
  - `未找到空间` → 先跑 `pool.bat setup`（它会建空间）

### 第 7 步：预热（`pool.bat` → `5`）
- **做什么**：让每个窗口启动一次、插件连接一次、访问一次目标站。**新号池必做一次。**
- **应该看到什么**：一行一行 `win=1 ... OK`；结束时 `预热完成：成功 N，失败 0`。
  中间会自动反复开关窗口，属于正常现象。
- **不是这样**：个别窗口 `FAIL` → **再跑一次 `pool.bat warm`**（只补失败的），
  连续失败就 `pool.bat doctor` 看第 9 节。

### 第 8 步：端到端自检（`pool.bat` → `8`，即 `pool.bat test`）
- **做什么**：真的出一张图，验证整条链路。
- **应该看到什么**：`自检通过：...output\selftest.png（1.3 MB，56s）`，然后打开图片能看到柴犬。
- **不是这样**：它会直接给出"建议：..."（比如"跑 pool.bat warm"）。

### 第 9 步：正式开始用
```bat
pool.bat gen "一只戴宇航头盔的柴犬，扁平插画风" --ratio 1:1 -o out\shiba.png
pool.bat batch prompts.txt --outdir output --concurrency 3      :: 批量
```

## 五、新手最常卡住的 12 个点

| 现象 | 原因 | 一句话解决 |
|---|---|---|
| `'python' 不是内部或外部命令` | 装 Python 没勾 PATH | 重装 Python，勾 Add to PATH |
| `pool.bat` 一闪就没了 | 双击时出错退出 | 用 cmd 进入目录再执行，或在菜单里看退出码 |
| 服务"未运行" | 没启动，或被不小心关了 | `pool.bat start` |
| 任务报 `浏览器插件未连接` | 新窗口没预热 | `pool.bat warm` |
| 任务报 `GPT pageFetch returned empty result` | 窗口没访问过目标站 | `pool.bat warm` |
| 任务报 `token 过期 / unauthorized` | 卡密 token 到期（一般 10 天左右） | 重新买/换卡密 → `pool.bat import accounts.txt --yes` |
| 模型"只回了文字，没画图" | 免费号偶发反问 | 本工具**已自动重试**；还失败就再跑一次 |
| 图片下不来（`403 / access denied`） | 结果图是内部链接，需要窗口 token | 本工具**已自动用 token 下载并校验** |
| 某些窗口一直失败 | 进了"错误冷却" | `pool.bat status` 看解冻时间；或 `pool.bat reset` 清场后重新预热 |
| 窗口打不开/异常退出 | 上次进程残留占着 profile | 本工具**已自动清理残留并重试**；实在不行 `pool.bat reset` |
| `缺 playwright` | 依赖没装全 | `pool.bat setup`（会自动补装） |
| 出图很慢 / 排队 | 窗口数不够或都在跑 | 加卡密扩容；或把并发降下来（`--concurrency 3`） |

**排错三部曲**：`pool.bat doctor` → `pool.bat logs --errors` → `pool.bat reset` 后重跑 `warm`。

## 八、安全与合规（请务必看）

- **只操作你自己拥有或已获授权的账号**。卡密的来源与合法性由你自己负责。
- 卡密文件 `accounts.txt`、数据库 `*.db`、日志都在 `.gitignore` 里，**不要**提交到公开仓库。
- 建议给每个窗口配独立出口 IP（一窗口一 IP），避免同 IP 多账号联动风控。
- 本工具会长期保存 access_token（用于免登录出图）。这是**为了可用性**的取舍：
  请把部署机器当作敏感机器对待（不要共享给不可信的人、不要放到公网）。
- 商用/对外提供服务前，请自行确认目标站点的服务条款与当地法律是否允许。
